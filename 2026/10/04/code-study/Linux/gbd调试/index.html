1、注意

当需要同时编译C与C++文件时推荐，gcc与g++分别编译，最后g++链接

C 头文件如果给 C++ 用，通常要加：

选项 含义 作用 阶段 注意事项
-Wall 开启常用警告 提示未使用变量、类型不匹配、缺返回值等 编译 不是“所有警告”，建议和 -Wextra 一起用
-Wextra 开启额外警告 比 -Wall 更严格，如未使用参数、符号比较等 编译 常与 -Wall 搭配
-g 生成调试信息 让 GDB 能看到源码、行号、变量名、类型 编译 调试必备；-g3 可包含宏信息
-O0 关闭优化 源码与机器码基本一一对应，方便单步调试 编译 调试推荐；-Og 是折中；发布常用 -O2
-Iinclude 添加头文件搜索路径 编译时去 include/ 找头文件 编译 -I 后跟目录，可写多个
-Llib 添加库文件搜索路径 链接时去 lib/ 找库文件 链接 -L 后跟目录，可写多个
-lm 链接数学库 libm 使用 sqrt、sin、pow 等数学函数 链接 -l 后跟库名，去掉 lib 前缀和 .so/.a 后缀
-o app 指定输出文件名 生成可执行文件 app 链接 不写 -o 时默认输出 a.out
