Installing the SDK

在深入使用 SDK 之前，请确保你的系统中已安装了 Python 语言。
Claude Python SDK 需要使用 Python 3.7.1 或更高版本。
您可以在终端中运行以下命令来检查当前使用的 Python 版本：python –version
准备好了 Python 环境，就可以使用 pip 来安装 Anthropic 软件包了。

二、理解消息的API格式

消息格式使我们能够将以对话形式提出的请求结构化为对 Claude 的调用，从而保持对话的上下文完整性。这种消息格式能够保留整个对话的历史记录，包括用户和助手发送的所有消息。这样，当 Claude 生成回复时，它能够获取到完整的对话上下文信息，从而得出更加连贯且相关的回答。

检查消息的响应情况

除了 content 之外， Message 对象还包含一些其他的信息：
  id – 一个唯一的对象标识符
  type - 对象类型，始终为“消息”
  role – 生成的消息在对话中的角色。无论何时，它都将是“助手”的角色。
  model - 负责处理请求并生成响应的模型
  stop_reason – 这是模型停止生成数据的原因。我们稍后会进一步了解这个问题。
  stop_sequence – 我们稍后会详细了解这一点。
  usage – 关于计费和使用限定的信息。包含以下内容：

  •   input_tokens – 所使用的输入标记的数量。
  •   output_tokens - The number of output tokens that were used.
  •   soutput_tokens – 实际使用的输出标记数量。
